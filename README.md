# Tab Studio 1.0

ギターやベースのTAB譜・五線譜を書いて、その場で鳴らして練習できるWindows用アプリです。インターネットにつながっていなくても使えます。

- TAB譜・五線譜の作成と編集（複数トラック、ギター6弦・7弦、ベース4弦・5弦、ドラム、キーボード）
- Guitar ProやTuxGuitarの譜面を開いて編集・再生
- テンポ・再生速度の変更、ループ再生、カウントインつきの練習再生
- ミキサー（音量・パン・リバーブ・ミュート・ソロ）、NAMアンプ、VST3プラグイン
- ギターやベースをつないで弾ける楽器入力（ASIO対応）。直近5分を常に録音しておく「Rewind」と、チューナーつき

## ダウンロードとインストール

1. [Tab Studio 1.0.0の配布ページ](https://github.com/0reo1024/Tab-Studio/releases/tag/v1.0.0)を開き、`Tab-Studio-1.0.0-Setup.exe` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックします。
3. 「WindowsによってPCが保護されました」と表示されたら、「詳細情報」→「実行」を押します（インストーラにはまだ電子署名がないため表示されます）。
4. 画面の案内どおりに進めると、スタートメニューに「Tab Studio」ができます。

**動作環境**: Windows 10 / 11（64ビット）。Windows用の部品「WebView2」が入っていないPCでは、インストール中に自動でダウンロードされます。Mac版は今回は配布していません。

前のバージョンが入っていても、そのまま上からインストールできます。設定や録音は引き継がれます。

## はじめての起動

スタートメニューの「Tab Studio」を開くと、最初の画面で次のどれかを選べます。

- **新規作成**: 曲名・テンポ・楽器を決めて、白紙の譜面から始めます。
- **ファイルを開く**: 手持ちの譜面を開きます。
- **最近開いた譜面 / 前回のタブを再開**: 続きから作業します。

## 譜面を書く

- 譜面上の位置をクリックし、キーボードの数字でフレットを入力します。Enterで確定、矢印キーで移動します。
- 音の長さ（音価）、強弱、スライド・ベンド・ハンマリングなどの奏法は、左の編集パネルか右クリックメニューから付けます。Ctrl+Bで奏法の詳細を開きます。
- ドラッグで範囲を選ぶと、コピー・貼り付けや、音価・奏法のまとめての変更ができます。
- トラックの追加・並べ替え・チューニング（完全4度などのプリセットあり）は「トラック」メニューから変更します。
- 取り消しはCtrl+Z、やり直しはCtrl+Yです。

## 再生と練習

- Spaceで再生・一時停止します。Ctrl+Spaceで再生開始位置に戻ります。
- 再生バーで、テンポ、再生速度、ループ範囲、カウントイン（クリックの回数）を設定できます。
- 「表示 → ミキサー」で、トラックごとの音量・パン・リバーブ・ミュート・ソロを調整できます。
- 伴奏の音声ファイル（MP3・WAV・FLACなど）を読み込んで、譜面と一緒に鳴らせます。

## 開ける形式・保存できる形式

| | 形式 |
|---|---|
| 開く | TabStudio（`.tabstudio`）、TuxGuitar（`.tg`）、Guitar Pro（`.gp3` `.gp4` `.gp5` `.gpx` `.gp`） |
| 保存・書き出し | TabStudio、TuxGuitar（`.tg`）、Guitar Pro、MIDI、PDF |

## 音について

- 標準の音色はGeneralUser GS（128種類のGM音色）で、アプリに入っています。
- **NAMアンプ**: ギター・ベースのトラックでNAMをONにすると、アンプの音で鳴らせます。内蔵のアンプモデルのほか、手持ちの `.nam` ファイルも追加できます。
- **VST3プラグイン**: ミキサーの「＋ FX」から、PCに入っているVST3プラグイン（BIAS FX 2など）を追加できます。VST2には対応していません。
- **SFZ音源**: Unreal Instrumentsの「Standard Guitar」など、別途入手したSFZ音源を、ミキサーのサウンド欄から選んで使えます。音源そのものはアプリに入っていません。

## 楽器入力（ギターをつないで弾く）

1. オーディオインターフェースにギターやベースをつなぎます。
2. 「ツール → 楽器入力（録音・練習）…」を開き、方式（ASIOを推奨。WASAPIも可）、デバイス、入力チャンネルを選んで「入力をオン」を押します。
3. 「モニタ」をONにすると、アプリのアンプ（NAM）やプラグインを通した音が聞こえます。

- **チューナー**: 楽器入力パネルの「チューナー」で、弾いた音の音程を表示します。
- **Rewind（直近5分）**: 「ツール → 設定…」の「楽器入力」で「Rewind（楽器の入力を常に録音する）」をオンにすると、入力中は直近5分を常に録音します。「いまの良かった」と思ったら、波形をクリックして聴き返したり、範囲を選んで保存したりできます。
- **ステレオ録音**: 入力チャンネルで「3+4（ステレオ）」のような2つ組を選ぶと、左右そのままのステレオで録音します。
- 保存した録音（テイク）は、「ミュージック」フォルダの「Tab Studio 録音」に入ります。

## データの保存場所

| 内容 | 場所 |
|---|---|
| アプリ本体 | `%LOCALAPPDATA%\Tab Studio` |
| 設定・直近の録音ファイル | `%APPDATA%\jp.tabstudio.desktop` |
| 保存したテイク | `ミュージック\Tab Studio 録音` |

譜面ファイルは、保存するときに選んだ場所に保存されます。

## アンインストール

Windowsの「設定 → アプリ → インストールされているアプリ」で「Tab Studio」を選び、「アンインストール」を押します。設定と録音を残したくない場合は、上の表の `%APPDATA%\jp.tabstudio.desktop` も削除してください。

## 困ったとき

- **音が出ない**: 楽器入力の「出力 / ドライバ」で、使っているスピーカーやオーディオインターフェースが選ばれているか確認してください。
- **ASIOが使えない**: 他のアプリ（DAWなど）が同じASIOドライバを使っていると使えません。そのアプリを閉じてから「もう一度つなぐ」を押してください。
- **SFZ音源が見つからない**: ミキサーのサウンド欄から、音源の `.sfz` ファイルを選び直してください。

## 開発者向け: ソースからビルドする

必要なもの: Node.js 22 と pnpm、Rust（stable）、LLVM（ASIO対応のビルドに使います）、Steinberg ASIO SDK（`third_party/asio_sdk` に置きます。ライセンスの都合でリポジトリには含めていません）。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm tauri build
```

インストーラは `src-tauri/target/release/bundle/nsis/` にできます。ASIOなしでビルドするときは、`src-tauri` の Cargo の既定機能を外します（`--no-default-features`）。
