# Tab Studio 1.1.0

Windows/macOS向けのオフラインTAB譜・五線譜編集／再生アプリです。複数トラックの編集、範囲コピー、奏法の設定、テンポ・速度調整、ループ再生に対応し、TG保存とGP・MIDI・PDFへの書き出しができます。

追加機能と操作方法は[0.3.37の開発内容](docs/development-0.3.37.md)を参照してください。

## 1.1.0 正式リリース

起動時の選択画面、ハーフベンド、3点のベンド編集、Ctrl+Bの奏法詳細、右クリックメニューの再配置と詳細ボタンのデザインを含む正式版です。WindowsインストーラとMac両機種向けZIPを配布します。

## 1.0.2の変更

右クリックメニューの「奏法の詳細」を、枠・背景・ホバー表示のあるボタンに変更しました。Windows開発版でメニューの表示と編集操作を確認しています。

## 1.0.1の変更

- 起動時に、新規作成と最近開いた譜面を選ぶ画面を表示します。設定の「一般 → 起動時の画面」で前回の譜面を開く方式に切り替えられます。
- 新規作成では曲名・テンポ・楽器を指定できます。
- ハーフベンド（半音）を追加し、エフェクト欄の重複した3連符ボタンを削除しました。3連符は音価欄に残しています。
- ベンド詳細の制御点を3つに統一しました。読み込んだ譜面のベンドは適用するまで変更しません。
- Ctrl+Bで奏法の詳細を開きます。設定でキーを変更できます。
- 右クリックメニューは奏法の詳細、音価、エフェクトの順で表示します。

## 起動

最新版1.1.0のMac配布は`release/1.1.0/Tab-Studio-1.1.0-mac-arm64-Install.zip`（Apple Silicon）または`Tab-Studio-1.1.0-mac-x64-Install.zip`（Intel）を渡します。ZIPを展開して`Install Tab Studio.command`を開きます。Macでのインストール・起動・音声再生は未確認で、Developer ID署名・Appleの公証はありません。詳しくは[Macテスト配布の手順](packaging/mac/README-ja.md)を参照してください。

初期版0.3.9のインストーラも`release/0.3.9`に残しています。旧版の手順は[インストール手順](packaging/INSTALL-ja.md)を参照してください。

このフォルダーの `Tab Studio.cmd` をダブルクリックしてください。または `release/1.1.0/win-unpacked/Tab Studio.exe` を起動します。実行フォルダー内のファイルはまとめて保管してください。

## 開発環境とビルド

Node.jsとpnpmを用意し、次の順に実行します。

```sh
pnpm install --frozen-lockfile
pnpm run prepare:assets
pnpm test
pnpm run build
```

開発中は`pnpm run dev`で画面を起動し、別のターミナルで`pnpm start`を実行します。Windows配布版は`pnpm run dist:win`、Mac上でのDMG・ZIP作成は`pnpm run dist:mac`を使用します。

生成物・依存パッケージ・テスト結果はGitの対象から除外しています。インストーラや配布ZIPはGitHub Releasesに添付してください。GitHub Actionsの「Build installers」は手動実行でWindowsとMacの配布物を作成します。Mac版にApple Developer ID署名・公証はありません。

## 引き継いだ機能

- `.tg`（1.5互換バイナリ・2.x ZIP/XML）、`.gp3`、`.gp4`、`.gp5`、`.gpx`、`.gp`の読み込み。

- クリック音5種類（標準・ウッドブロック・リムショット・ハイハット・電子音）と音量0〜100%。
- ファイル/編集/表示などのWindowsメニュー。編集/トラック/再生コントロールの表示切り替え。F11で全画面。
- 未保存の編集内容をローカルに復元用として保存し、次回起動時に復元するか選択できます。

譜面の弦をクリックして数字を入力するか、Enterで譜面上の青いマーカーに数字を入力します。Spaceで再生/その場で停止、Ctrl+Spaceで再生開始位置に戻って停止、Ctrl+N/O/Sで新規/開く/保存、Ctrl+Shift+Sで名前を付けて保存します。基本操作はTuxGuitarに合わせています。

## 制限と検証

高度な奏法やファイルバージョンの完全互換ではありません。TGの装飾音、歌詞、コード図などには未対応部分があり、読み込み情報に警告を表示します。TG/GPファイルは40MBまで、交換するSF2音源は200MBまでです。

音源は同梱SF2のGM音源です。専用の高品質ギターサンプルやアンプシミュレーターは未追加です。「SoundFontを交換」で別のSF2音源を利用できます。実際のスピーカー出力の音質・遅延は試聴評価していません。

モデル・読み込み・音価・クリック波形・保存終了・書き出しの自動テスト79件と、Windows版Electronでの弦クリック/数字入力/選択枠/再生/各形式読み込み/保存成功/保存キャンセル/書き込み失敗/保存せず終了を検証しています。GP・TGの書き出し後の再読み込み、MIDIの音符・テンポ・拍子、PDFの複数ページ・表示トラック・五線譜付きの出力も検証しています。テスト結果の画面は `test-results` に保存されます。
