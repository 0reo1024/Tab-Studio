    キーボード操作

    以下は標準の割り当てです。「ツール → 設定 → ショートカット」で変更できます。

    弦をクリックして編集位置を選び、数字でフレットを入力。ダブルクリック、またはEnterで譜面上の選択位置に数字を入力できます。

    • 音符をダブルクリックして数字入力。もう一度クリックすると編集メニューが開きます。右クリックでも音符を選択して開けます。数字が変わるたびに試聴し、音符を1回クリックしても音を確認できます。試聴のタイミングとクリック時の試聴は「設定 → 一般」で変更できます。
    • 矢印：音符・弦を移動。Shift＋上下でカーソルから前後の行まで選択
    • Delete：音符を削除 / Ctrl+Delete：拍を休符に
    • 音符選択時のShift＋左右：半音上下 / Shift＋上下：音高を保って弦を移動。Ctrl＋上下：符尾の向き。
    • Ctrl＋1/2/4/5/6/7/8：全音符〜64分音符。L：タイ / T：テキスト。Ctrl+B：奏法の詳細。
    • Ctrl＋Tab：譜面タブ切り替え / Ctrl＋W：現在の譜面を閉じる。
    • ＋ / −：音価を長く / 短く
    • ＊：付点 / ／：3連符
    • P：パームミュート / X：デッドノート / V：ビブラート / H：ハンマリング / O：ゴーストノート
    • Insert：休符の挿入
    • Ctrl+End：末尾に小節を追加 / Ctrl+Insert：選択小節の前に1小節挿入 / Ctrl+Shift+End：小節を挿入… / Ctrl+D：選択小節を複製 / Shift+Delete：選択小節を削除
    • 拍子・小節 →「拍子を変更（小節を指定）…」：開始〜終了小節だけ拍子を変更（範囲を選んでから開くとその範囲が入ります）
    • Space：再生・その場で停止 / Ctrl+Space：再生開始位置に戻って停止 / F11：全画面
    • Ctrl+N/O/S：新規・開く・保存 / Ctrl+Shift+S：名前を付けて保存
    • Ctrl+Z/Y：取り消し・やり直し
    • ドラッグ / Shift＋クリック / カーソルだけのときShift＋左右：拍の範囲選択（和音はまとめて選択）。青枠の範囲には強弱記号・エフェクトを一括適用できます。ドラッグ・Shift＋クリック・小節の範囲選択で選んだ範囲では、Shift＋左右で半音、Shift＋上下で弦移動、Ctrl＋上下で符尾の向きもまとめて変わります（Shift＋方向キーで広げている途中の範囲はそのまま広がります）。カーソルだけのときShift＋上下：前後の行まで選択。Ctrl＋Shift＋左右：先頭・末尾まで選択
    • Ctrl+C/X/V：選択範囲のコピー・切り取り・上書き貼り付け（未選択なら現在の拍）。Ctrl+Shift+V：後ろをずらして挿入貼り付け。Delete：選択範囲を休符化。Escape：範囲を解除
    • 小節単位の選択：編集メニューの「小節の範囲選択…」 / Ctrl+A：全小節選択
    • 五線譜：Enterで音高入力。音符のダブルクリック後にもう一度クリックで編集メニュー。上下で音高移動、Alt＋上下で半音、Shift＋A〜Gで音名入力
