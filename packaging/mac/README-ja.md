# Tab Studio 1.1.0 — Mac向け配布

Apple Silicon（M1以降）はarm64版、Intel Macはx64版を使用します。macOS 12以降を対象にしています。

1. ZIP全体を展開します。
2. `Install Tab Studio.command`を開き、表示される確認画面でインストールします。
3. アプリは自分のホームフォルダの`Applications/Tab Studio.app`に入ります。既存のアプリは同じフォルダ内に日時付きでバックアップします。

インストーラはアプリのコピーとMac上でのローカル署名を行います。管理者権限は不要です。署名確認に失敗した場合はインストールを中止し、既存のアプリを残します。

Windows上でパッケージを作成し、ZIP・CPU種別・バンドル情報・同梱アプリの内容を検証しています。Macでのインストール・起動・音声再生は未検証です。DMGではありません。Apple Developer ID署名・Appleの公証はありません。ローカル署名は開発元の認証を意味しません。

インストールスクリプトやアプリを開いた際、開発元を確認できない旨の表示が出る場合は、入手元を確認したうえで「システム設定 → プライバシーとセキュリティ → このまま開く」から個別に許可してください。セキュリティ設定全体を無効化する必要はありません。破損・マルウェアの警告や署名エラーが出る場合は、警告とターミナルの表示を開発者に伝えてください。

[Apple公式の初回起動の案内](https://support.apple.com/ja-jp/102445)

アンインストールは`~/Applications/Tab Studio.app`をゴミ箱へ移動します。譜面ファイルや保存したデータは自動で削除しません。

## 試してほしい操作

- 同梱デモの表示と再生・停止。
- GP/TGファイルを開き、音符を編集し、コピー・貼り付け・取り消し。
- 別名でTGに保存し、開き直す。元の譜面を残してテストしてください。
- テーマ・トラック表示を変更して再起動する。
- PDF出力。

現在の初期ショートカットはControlキーを使用します（Commandへの自動置き換えはありません）。Spaceで再生・その場で停止、Control+Spaceで再生開始位置に戻って停止します。「ツール → 設定 → ショートカット」で変更できます。

問題が出たら、Macのチップ名・macOSのバージョン・操作手順・エラー文またはスクリーンショットを開発者に伝えてください。
