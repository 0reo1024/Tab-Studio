# Tab Studio 0.3.37 開発版

2026-10-07。追加機能の設計書にある項目1・2・3・4・5・6・10を実装。

## 使い方

| 機能 | 開く場所・操作 |
|---|---|
| カウントイン | プレーヤー → 練習設定…。なし／1小節／2小節。再開時と各ループ前のカウントは個別に設定。Spaceで取り消し、Ctrl+Spaceで開始位置へ戻って停止。 |
| スピードトレーナー | プレーヤー → スピードトレーナー…。ループ範囲または選択した拍の範囲を指定し、開始・終了速度、上昇幅、反復回数を設定。Space／Ctrl+Spaceで解除。曲本来のテンポは変更しない。途中の手動移動で短縮した周回は回数に含めない。 |
| 奏法の詳細 | エフェクト → 奏法の詳細…。ベンドの形と制御点、スライド、ハーモニクス、ビブラート、トリル、トレモロピッキング。選択範囲にも一括適用でき、設定した種類以外の奏法は保持。試聴は明示的な「試聴」で行う。 |
| 曲構成 | 表示 → 曲構成。小節マーカーから区間を生成し、移動・範囲選択・ループ範囲設定・名前変更。区間選択は再生位置を動かさない。 |
| 目的別貼り付け | 編集 → 形式を選んで貼り付け…。すべて／リズムのみ／奏法・強弱のみ／コード・テキストのみ、反復回数、挿入を指定。通常のCtrl+VとCtrl+Shift+Vには確認画面を追加していない。 |
| 鍵盤・ドラム入力 | 表示 → 鍵盤・ドラム入力。選択トラックに応じて鍵盤またはドラムパッド。和音への追加、入力後の次拍移動に対応。音価は既存のパレットを使用。鍵盤トラックの上下段・声部は現在選択した箇所へ入力し、自動で振り分けない。 |
| MIDIステップ入力 | 補助パネルの「MIDIステップ入力」で機器を検索・接続。チャンネル指定と試聴を設定できる。押した鍵盤をすべて離すと一つの和音として確定して次へ移動。文書・編集位置・譜面内容が途中で変わった場合は取り消す。 |
| 譜面・印刷レイアウト | 表示 → 譜面・印刷レイアウト…。譜面サイズ、行・段の余白、文字サイズ、改行、印刷の改ページ、A4／Letter／A3、余白、向き、曲名・ページ番号・トラック名・コード・テキスト。PDF出力画面からも開ける。 |

曲構成と音符入力は同じ閉じられるパネルを共有する。初回は非表示。レイアウト設定はTGの補足プロジェクト情報へ保存し、古いファイルも引き続き開ける。

## 編集の速さ

- 数字入力の既存の局所更新を維持し、音高・強弱・単純な奏法・符尾変更にも拡張。
- 同じ音価・チューニングで、独立した音符を上書きする貼り付けは、変更部分だけを確定。履歴は変更した拍とその上位要素のコピーで保持する。
- ベンド・タイ・ハンマリング等の接続関係、音価の変更、挿入、範囲拡張が必要な処理は、関係を再構築する経路を使用。すべての操作で全曲の再構築をなくしたわけではない。
- 入力と移動は背景描画を待たない。音楽データのMIDI更新は再生開始時に行い、文字入力ごとには行わない。

実測：168小節、2トラック、4,032音、8回の数字確定＋右移動で、移動表示までの中央値18.1ms、範囲16.7〜22.6ms。変更処理の中央値12.5ms。各入力でのMIDI再読み込み・全曲モデルの置き換えは0回。背景の譜面描画完了は約381〜433msで、これは入力待ち時間とは別。環境・音符密度・接続奏法によって変わる。

測定結果：`test-results/input-move-1791379480692/report.json`。

## 検証

- 型チェックとビルド成功、129件のモデル・保存・編集テスト成功。
- 通常入力、取り消し／やり直し、音色変更、位置・スクロール保持、休符の選択、範囲選択中の再生、Space／Ctrl+Spaceを実際のWindowsウィンドウで確認。
- 詳細奏法のGP／TG保存・再読み込み、ベンドの実際のMIDI生成を確認。
- カウント開始・取消・毎周回カウント、トレーナーの段階変更・完了・通常速度への復帰を確認。
- 鍵盤、ドラム、模擬MIDI機器による和音確定と次拍移動を確認。実物のMIDI機器での動作は未確認。
- LetterサイズのPDF、指定小節末での改ページ、空白ページがないことを確認。印刷用描画は通常の譜面から分離。

MIDIはステップ入力。リアルタイム録音と自動採譜は対象外。奏法・テキストだけの貼り付けでは拍位置の一致が必要で、一致しない場合は変更前に理由を表示する。装飾音を含む範囲は「すべて」または「リズムのみ」を使用する。

Windows版：`release/0.3.37/win-unpacked/Tab Studio.exe`。Mac版は0.3.36の配布物を維持。
