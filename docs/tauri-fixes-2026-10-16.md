# Tauri版の修正（2026-10-16）

| 依頼・不具合 | 原因と修正 |
|---|---|
| 曲頭の1音目が鳴らないことが多い（James Franco） | 開いた直後の再生カーソルはtick 2にあり、そこへのシークでtick 0の音（Gtr1の1音目、Gtr2の和音）が飛ばされていた。tick指定のシークは4 tick手前（300 bpmで約1 ms）までの音を鳴らす。 |
| DIの音を変えると音が出なくなる／タブ切替で鳴らなくなる | ① 差し替えで不要になったSFZ音源の解放（数秒）を、エンジンのロックを握ったままコマンド送信のたびに行っていた。その間は再生・停止・状態取得がすべて止まった。解放は別スレッドで行う。② 音源の読み込み中は再生ボタンが無効で、Spaceは無効なボタンを押すだけで何も起きなかった。読み込み中も再生を受け付け、終わり次第再生する（ステータスに表示）。③ NAMなしの譜面へ切り替えるとSFZ音源を破棄し、戻すたびに約9秒かけて作り直していた。手放したSFZ音源を直近2つまで保持して再利用する（戻すと約0.3秒）。 |
| Bass DIを Standard / Growly / 今の（Fashion）から選べるように | ミキサーのサウンド欄で Bass DI (Fashion)・Bass DI (Standard)・Bass DI (Growly) を選べる。既定はFashion。StandardはStandard Bass V2のfinger。NAMのベースアンプ3機種でFashionと平均0.5 dB以内にそろえた（Standard −3 dB、Growly −3 dB）。 |
| 録音中の赤をやめてRewindに。パネルの外をクリックしたら閉じる | 常時録音の表示は「⟲ Rewind」で、色はアクセント色。楽器入力パネルは外側をクリックすると閉じる（入力は止まらない）。設定の項目名も「Rewind（楽器の入力を常に録音する）」にした。 |
| ウィンドウ幅を縮めたら譜面も縮めて、必ず全体が見えるように | 譜面ペインがページ幅より狭いと、ページ幅と表示倍率を一緒に縮める（改行位置は変わらない）。文書のズーム値は変えない。最小ウィンドウ幅1024pxまで横スクロールなし。 |

検証（release版、スピーカーはミュート）：

- 修正前に再現：開いた直後にSpaceで再生すると、Gtr1の1音目が0.14秒遅れ、Gtr2の和音は鳴らなかった。2つ目の譜面を開くと`audio_status`が9.2秒止まった。DI切替直後のSpaceは無視された。
- 修正後：曲頭は両トラックとも0〜0.01秒で発音。タブ切替4回はすべて0.02秒以内に再生開始した。DI切替は保持中の音源なら即座に再生する。初めての組み合わせは読み込みが終わると自動で再生する（譜面1つ分のStandard Guitarで約7〜10秒、その間ステータスに表示）。状態取得の待ちは、セッション最初の譜面を開いたときに1回だけ約1.1秒（修正前から同じ）、それ以外は最大0.23秒。
- `scripts/tauri-bass-di-check.mjs`：3種の選択、保存、発音。再生中の切替で途切れは0.16秒。
- `scripts/tauri-fit-width-check.mjs`：実ウィンドウを1500→1024pxに縮め、横スクロールなし、ズーム表示・未保存状態は不変。
- メモリ（tab-studio.exe）：Francoを再生して1.6 GB。タブ切替とDI切替を8回繰り返して1.7 GB。保持数を4にすると2.2 GBになったため、2にした。
- `scripts/tauri-fit-width-check.mjs` は1024 pxで、譜面上の音符をクリック→Enter→フレット入力まで確認した。入力欄は音符の上に出て、値も反映された。
- `pnpm test` 288件、`cargo test`（tabstudio-audio 62件、src-tauri 24件）合格。
- 既存のrelease版チェック：regression、guitar-di、native-playback、bass-slap、edit-playback が合格。bass-slapは、スラップ用音源の読み込みで再生開始が待たされることを確かめる判定。ロック修正で待ち時間が約0.1秒縮んだため、しきい値を0.7秒から0.3秒に下げた（実測0.66秒）。
- live-input：ASIOのNano Cortexが接続されておらず（ASIOデバイス0件）、ASIOでは入力を開けなかった。WASAPIに切り替えると最後まで合格した。Rewind表示、外側クリックで閉じること、ピルから開き直せることも確認した。
