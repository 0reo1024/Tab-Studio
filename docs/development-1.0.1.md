# Tab Studio 1.0.1 開発版

## 起動と新規作成

起動すると左に新規作成、右に最近開いた譜面を表示します。曲名・楽器・BPMを指定して4小節の譜面を作成できます。最近の譜面は選択して「開く」、またはダブルクリックで開きます。「ファイルを開く…」から別の譜面も選べます。

「設定 → 一般 → 起動時の画面」で「前回開いていた譜面」に切り替えられます。初期設定は新規作成・最近開いた譜面の画面です。旧設定からの更新時もこの初期設定を使用します。未保存データがある場合は、復元確認を先に行います。

## 奏法

- エフェクト欄の3連符を削除。音価欄の3連符は維持。
- ベンドの隣にハーフベンド（半音）を追加。全音ベンドと相互に切り替えられます。同じボタンを再度押すと解除します。
- ベンド詳細のグラフは常に3つの制御点を表示。外部ファイルの曲線は開いただけでは変更せず、適用時に編集した曲線へ置き換えます。
- Ctrl+Bで奏法の詳細を開きます。「設定 → ショートカット」で変更できます。
- 右クリック編集メニューは、奏法の詳細 → 音価 → エフェクト → 編集 → 拍子 → 強弱記号 → 音符/エフェクト → コピー操作の順です。

## 検証

132件のモデルテストと型検査が成功しました。Windows配布用アプリで、起動画面、楽器・テンポの指定、最近のファイル、存在しないファイルからの復帰、起動設定の保存と再起動、ベンド3点表示、キャンセル時の元曲線保持、半音/全音ベンド、ショートカット、右クリックメニュー、範囲選択と再生、既存の編集・練習機能を確認しています。

インストーラの埋め込みアーカイブを検証し、展開したアプリの起動・音源・基本キー操作・終了確認が成功しました。OSへのインストール/アンインストールの往復確認は行っていません。

168小節・2トラック・4032音の入力確認では、入力確定後の移動待ちの中央値は20.9ms（8回）。音符入力ごとの全曲置換・MIDI再読み込みは0回でした。譜面の背景再描画の完了時間とは別の値です。

Windows開発版のみ更新しています。Mac配布版は1.0.0です。
